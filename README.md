# Primer_Trabajo_Practico_IA

Repositorio para subir el código correspondiente al primer TP de la asignatura Inteligencia Artificial

## Para realizar test se debe seguir los siguientes pasos:

. Primero se debe ejecutar el comando pip install -r requirements.txt para instalar las dependencias(si es que no se instalaron las mismas).

. Luego se debe ir a la linea 163 del archivo main.py y cambiar el valor de la variable query por la consulta que se desea realizar.

. Finalmente se debe ejecutar el comando python main.py para ejecutar el programa.

. Por cada test se debe registrar en la carpeta testings un archivo txt que lleve por nombre las especificaciones de la computadora utilizada y dentro del mismo se especifica la query realizada
los chunks y el overlap utilizados.

Se integro un sistema de seleccion de variantes de configuracion al momento de crear la BD local, se utilizo IA para generar dicho codigo, la razon de dicho sistema es para cumplir con los requisitos del TP, se utilizao IA ya que la tarea era sencilla pero tediosa, ademas de que el
programador no cuenta con el conocimiento necesario para codificar dicho codigo y no tenia intencion alguna de codearlo.
